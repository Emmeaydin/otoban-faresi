# Otoban Faresi

Tarayıcıda oynanabilen, dokunmatik ve klavye kontrollerini destekleyen dikey otoyol yarışı.

## Oyna

GitHub Pages etkinleştirildiğinde oyunu `index.html` üzerinden doğrudan tarayıcıda açabilirsin. Dosyayı indirip bilgisayarında açarak da oynayabilirsin.

## Kontroller

- **Bilgisayar:** Ok tuşlarıyla yön ver, yukarı okla gaz ver, aşağı okla fren yap.
- **Telefon ve tablet:** Ekrandaki sol/sağ, gaz ve fren düğmelerini kullan.

Yolda trafiğe ve engellere dikkat et, benzin bidonlarını topla, 1.000 metredeki checkpoint’leri geç ve 3. checkpoint’te uzay gemili finale ulaş.
